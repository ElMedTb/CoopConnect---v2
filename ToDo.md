# Projet de création d'entreprise

## Consignes

Ce repository doit contenir tous les documents liés à votre projet au fur et à mesure de son avancement. Pas seulement la partie code mais aussi les documents liés à votre projet de création d’entreprise.

C’est votre responsabilité de garder ce repository clair, lisible et à jour. Vous pouvez l’organiser comme vous voulez mais ce fichier de README doit être le point d’entrée qui explique le projet :

- qui vous êtes  
- quel est votre projet  
- plan du repository  
- commandes pour lancer le code  

## Livrables

- **Premier livrable** (la date limite vous sera spécifiée, ce sera en janvier) : un unique fichier PDF contenant les éléments précis et structurés de la conception de votre future application (qui sera soit un produit réalisé par votre entreprise soit un programme nécessaire à sa création, son développement ou sa gestion, et il y aura obligatoirement une partie IA) sous la forme de tous les diagrammes de cas d’utilisation UML dûment commentés. Nous pourrons vous interroger individuellement oralement sur ces diagrammes pour évaluer votre compréhension et votre maîtrise.

- **Deuxième livrable** (la date limite vous sera spécifiée, ce sera en mars) : un POC (programme informatique : preuve de concept) qui fonctionne. Nous sommes intéressés par les fonctionnalités les plus complexes et celles impliquant de l’IA, mais pas du tout par les interfaces graphiques ou les fonctionnalités simples ou classiques. Nous pourrons vous interroger individuellement oralement sur le code informatique de ce POC pour évaluer votre compréhension et votre maîtrise.

- **Livrable final** : le POC finalisé, sur GitHub, tous les codes informatiques permettant d’exécuter votre POC + une documentation d’installation + une documentation d’utilisation.
