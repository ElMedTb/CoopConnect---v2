# Product

## Register

product

## Users

Small business owners, cooperative managers, and independent operators in Morocco (gérants, artisans, farmers, TPE/PME leads). They open the app during working hours to post surplus resources, check what nearby actors need, and act on AI-suggested matches. Context is mixed: desktop in an office or mobile in a warehouse. They are pragmatic, time-constrained, and skeptical of tools that add friction.

Secondary users: MIAGE / EMSI academic evaluators assessing the platform's UX and technical ambition.

## Product Purpose

CoopConnect AI is a resource exchange platform for the Moroccan circular economy. It lets individuals, cooperatives, businesses, and associations publish listings for surplus goods, skills, spaces, or services, and then uses AI matching (content similarity + geographic scoring) to surface the best exchange opportunities. Success means real exchange volume, measurable CO2 avoided, and a local economic network that would not otherwise have formed.

## Brand Personality

Trustworthy, local, practical. The platform is a competent tool that respects the user's time. It does not moralize about sustainability — it demonstrates it through outcomes. Voice is direct, in French, without jargon or inspirational fluff.

## References

Linear and Notion: calm information hierarchy, purposeful whitespace, zero visual noise. The interface disappears so the work — finding a match, starting an exchange — stays central. Typography-led structure, not decoration-led.

## Anti-references

NGO / aid-org aesthetic: muted earth tones, stock photography of handshakes and fields, warm serif headlines, "making a difference" copy. This is a structured economic platform, not a grant report. The ecological mission is a feature, not the entire personality.

## Design Principles

1. **Platform, not poster.** Every screen should feel like a tool that works, not a campaign about values. Sustainability signals through outcomes (CO2 évité, échanges réalisés), not through visual cues borrowed from environmental NGOs.

2. **Earn the green.** Forest green is reserved for primary actions, active states, and data signals tied to the ecological mission. It should never be background wallpaper, icon tinting, or decoration.

3. **Local-first specificity.** Geographic proximity is a core feature. Design should surface location context prominently without making the UI feel like a map app. Distance and region should be legible at a glance.

4. **Information hierarchy over ornament.** Match the density of the data to the discipline of a Stripe or Linear: no unnecessary whitespace, no decorative cards, no repeated empty states. Dense but never crowded.

5. **Trust through consistency.** The same typographic scale, the same spacing rhythm, the same component behavior across landing and product. A user who arrives from the landing page should feel continuity the moment they log in.

## Accessibility & Inclusion

WCAG AA minimum across all surfaces. 4.5:1 contrast ratio for body text, 3:1 for large text and UI components. All interactive elements keyboard-navigable and screen-reader compatible. Focus indicators visible (currently defined as `outline: 2px solid #166534`). French is the primary language; UI copy should be evaluated for reading level appropriate to a mixed-education user base.
